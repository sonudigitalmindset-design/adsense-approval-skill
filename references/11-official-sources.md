# Official sources

Recheck these pages before stating a current rule as fact. Google
changes policies and moves Help pages. When a link redirects, follow
it to the live page and update this file.

Last checked: 17 November 2026. All links below were reached through
web search results or are the well-known AdSense Help entry points.

## How to verify a rule in 2 minutes

1. Open the AdSense Help Center and search for the exact topic.
2. Read the page, not a blog summary of it.
3. Note the date you read it and the exact wording.
4. If the page contradicts this skill, the page wins. Update the skill
   and record the change in `CHANGELOG.md`.
